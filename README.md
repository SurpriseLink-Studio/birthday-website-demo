# Birthday Website Demo — SurpriseLink Studio

A responsive, single-page birthday celebration website.

## Preview locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Included
- Responsive premium plum, champagne-gold and cream visual theme
- Sample recipient name and editable celebration copy
- Memory highlights and personal note sections
- Interactive surprise reveal with confetti
- Original browser-synthesised melody (user-initiated; no autoplay)
- Reduced-motion support and accessible button states

## Personalising for a customer
Edit the sample name "Aarav", the note, memory cards and final wish in `index.html`. Replace sample text with customer-approved content before delivery.

## Important
This repository is a demonstration template. Do not publish personal photos, names, or messages without the customer's permission.
